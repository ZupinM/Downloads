Each firmware download has a matching `.ini` file next to it in the same folder.

**Helios Analytics** runs on Windows 7, 10 and 11 (.NET Framework 4.0). Unzip and start `HeliosAnalytics.exe`.

**Helios Mobile** requires Android 5.0 or newer and a USB-C to USB-C cable (USB-B to USB-C for Micro-F).
Allow installation from your browser when Android asks.
